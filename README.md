## About
This repository contains a Flutter application. The goal of the project is to provide an accessible foundation that can be extended with features related to sign-language communication.

## Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- An editor such as VS Code or Android Studio
- Xcode (macOS) for iOS development, Android Studio for Android development

### Install
```bash
git clone https://github.com/alabelguith-a11y/SignBridge-.git
cd SignBridge-
flutter pub get
```

### Run
```bash
flutter run
```
